fritzfax for Windows - send faxes through an AVM FRITZ!Box
=============================================================

Start:   fritzfax-gui.exe  (the window)
         fritzfax.exe      (the command line: fritzfax.exe --help)
Check:   fritzfax.exe selftest

Unzip the folder anywhere (for example into Documents) and start fritzfax-gui.exe.
Windows may warn that the publisher is unknown ("Windows protected your PC"): the program is
not signed. Click "More info", then "Run anyway".
Office documents need LibreOffice (https://www.libreoffice.org); PDF and images work without it.
Settings: %APPDATA%\fritzfax   Send log: %LOCALAPPDATA%\fritzfax

fritzfax fuer Windows - Faxe ueber eine AVM FRITZ!Box senden

Start:   fritzfax-gui.exe  (das Fenster)
         fritzfax.exe      (die Kommandozeile: fritzfax.exe --help)
Pruefen: fritzfax.exe selftest

Den Ordner irgendwohin entpacken (zum Beispiel nach Dokumente) und fritzfax-gui.exe starten.
Windows warnt eventuell vor einem unbekannten Herausgeber ("Der Computer wurde durch Windows
geschuetzt"): das Programm ist nicht signiert. "Weitere Informationen", dann "Trotzdem ausfuehren".
Office-Dokumente brauchen LibreOffice (https://de.libreoffice.org); PDF und Bilder gehen ohne.
