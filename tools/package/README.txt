fritzfax __VERSION__ - send faxes through an AVM FRITZ!Box (Linux x86_64)

Start without installing:   ./fritzfax/fritzfax            (GUI)
                            ./fritzfax/fritzfax --help     (command line)
Install for this user:      ./install.sh                   (~/.local, menu entry)
Check this system:          ./fritzfax/fritzfax selftest [--gui]
Remove:                     ./uninstall.sh

Runs on Linux with glibc 2.34 or newer (Debian 12+, Ubuntu 22.04+, Fedora, Arch, Gentoo, ...).
Package "...-libreoffice": includes LibreOffice __LIBREOFFICE__ for office documents (Word, Excel,
...). Without it, PDF and images work; office documents need a LibreOffice of the system or must
be saved as PDF first.
